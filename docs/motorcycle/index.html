游戏内容简介:
《极速狂飙2豪华版》是一款老少皆宜的全动感遥控赛车类型游戏机，色彩外观绚丽，本机台是一款赛车类游戏，可以让玩家体验身临其境的比赛现场，玩家坐上机台，选好赛车，比赛开始后，通过控制好方向盘来控制赛车的方向，躲避障碍物以及捡取相应的道具，可变身成机器人，最终超越每个关卡的坏蛋，并保持领先到终点，则成功抓捕坏蛋，并进入下一关卡。总共四个关卡，每成功抓捕一个坏蛋，警官等级升高一级。
操作说明:
1.玩家投入适当的代币，按下开始按钮开始游戏。 2.通过开始按键，选择自己喜欢的赛车和赛道。 3.通过控制方向盘来控制赛车移动，超越每个关卡的坏蛋，并保持领先到终点，则成功抓捕，进入下一关卡。4.总共四个关卡，每成功抓捕一个坏蛋，警衔等级升高一级。
