# 图片存储双后端：阿里云 OSS 预签名直传（默认）+ CF R2（保留）

2026-10-21 当晚修订：全量迁 R2 上线数小时后，运营方反馈国内访问 CF R2 图片很慢。遂改为双后端：管理端选图时可选**阿里云 OSS**（Worker 生成 V1 预签名 PUT URL，浏览器带签名 Content-Type 直传北京桶，不经 CF；保存时 Worker 服务端 CopyObject 转正式键）或 **CF R2**（原绑定直传流程）。正式键规则两后端统一 `amusement/<设备id>/<栏位>.<扩展名>`；库里 OSS 图存完整 https 直链、R2 图存 /img/ 站内路径，图片字段校验只接受这两类。本决策部分取代 0002 的"弃用 OSS"。实施事实：桶 awhf-oss-app 为 **public-read-write**（匿名可写，沿用既有 smart-ex擎应用的设定，未改动，已向运营方提示风险）；桶 CORS 追加了一条仅允许本站域名的 PUT 规则（原规则原样保留）；AK/SK 只存 Worker secrets，未入代码与仓库（该对密钥曾在沟通中明文流转，运营方知情选择继续使用）。
