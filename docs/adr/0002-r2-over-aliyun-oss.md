# 图片存储选 Cloudflare R2（Worker 绑定直传），弃用阿里云 OSS

图片链路曾计划用运营方已有的阿里云 OSS 桶（awhf-oss-app）+ 预签名直传（2026-10-21 上午已把摩托页 8 张图手动传至 OSS 并替换页面链接），构建中运营方改为"OSS 也用 CF 自带功能"，遂全面转 R2：管理端选图即传（Worker 鉴权后经 R2 绑定写入，无需任何 AK/SK、无需 CORS 配置），对象键 `amusement/<设备id>/<栏位>.<扩展名>`，经 `/img/` 路径公开读取。收益：零密钥管理（此前那对 AK/SK 已在沟通中明文流转过，转 R2 后应立即在阿里云控制台禁用/删除）、零出口流量费、与 Worker/D1 同域一体化。代价：R2 桶落在 WNAM（创建接口带 APAC 位置提示持续超时，弃用后回落默认区），靠 CF 边缘缓存（`/img/` 响应 max-age=86400）抵消，仅首次访问回源。原有 8 张 OSS 图迁入 R2。
