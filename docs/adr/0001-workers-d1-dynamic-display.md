# 展示页从 GitHub Pages 静态站迁到 Cloudflare Workers + D1 动态渲染

2026-10-21 重构：设备展示页从"每设备一个手写 HTML 的 GitHub Pages 静态站"改为 CF Worker 服务端渲染——`/d/<id>` 按设备记录（D1）填充，运营方通过 `/admin` 管理端增改设备、上传图片（R2）、下载页面二维码。起因：设备陆续增加（同类不同厂家不同型号），手写页面+手动换图不可持续，需要一个带后台的单一数据源。迁移无兼容负担（此前贴纸仅测试未印刷张贴）。GitHub Pages 静态站已由运营方手动关闭，`docs/` 目录保留为历史资料与灾备素材。
